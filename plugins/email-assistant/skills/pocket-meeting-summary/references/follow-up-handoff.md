# Follow-up handoff

After a report is saved and verified, apply [pocket-meeting-follow-up](../../pocket-meeting-follow-up/SKILL.md) in the same task unless the user requested only the report or excluded email. Pass these accepted facts directly; do not make the user re-invoke the workflow or copy the report:

- Title, date/time/timezone, recording ID/source and saved report Page ID/link.
- Confirmed present attendees, supplied addresses, attendance evidence and unresolved identities; distinguish invitees, absentees and people only mentioned.
- Executive summary, decisions, actions with stated owners/deadlines, external commitments and open questions; preserve unknowns.
- Source limitations and audience, emphasis or exclusion instructions.

An index failure does not block a draft from a verified saved report; disclose it separately. Failed retrieval/verification without a reliable report cannot support a speculative handoff. If the follow-up skill is missing, deliver the report and explain the draft limitation.

Return report/index links with the draft and material limitations. Do not claim a failed index was saved. No authorization to send email, create mailbox drafts or change Pocket records is implied.
